Вам нужен Windows-сервис типа VPN Kill Switch с системной блокировкой сети, контролем процессов и GUI в системном трее.

Я бы предложил реализовать его как отдельное Windows-приложение из двух компонентов: фоновой службы Windows и приложения-индикатора в Tray.

## 1. Основная логика работы

## Состояния системы

Зелёный

VPN подключён

- Сервис проверяет наличие VPN-туннеля.
- Сетевой доступ разрешён.
- Мониторинг соединения продолжается.

  Красный

  VPN отключён
- Немедленно блокируется весь сетевой трафик.
- Блокировка действует для всех приложений и пользователей Windows.
- Запускается контроль процессов.

  Жёлтый

  Заблокировано вручную
- Сеть заблокирована независимо от состояния VPN.
- Сервис продолжает мониторинг.
- Разблокировка производится по заданным правилам.

## 2. Мониторинг VPN

Нельзя полагаться только на наличие VPN-интерфейса: интерфейс может существовать, даже если туннель фактически не работает.

Предлагаю использовать несколько проверок:

- Наличие VPN-интерфейса.
- Наличие маршрута через VPN.
- Проверка доступности контрольного IP через VPN.
- Проверка реального IP-маршрута.

При потере туннеля срабатывает Kill Switch.

Важно: блокировка должна работать на уровне Windows Filtering Platform (WFP) или Windows Firewall с политикой Default Deny, а не просто отключением сетевого адаптера.

## 3. Мониторинг приложений

Пока действует блокировка, сервис отслеживает запущенные процессы из заданного списка.

Например:

| Приложение | Правило                 |
| ---------- | ----------------------- |
| app1.exe   | Запрещает разблокировку |
| app2.exe   | Запрещает разблокировку |
| app3.exe   | Запрещает разблокировку |

Если хотя бы один экземпляр указанных приложений работает, кнопка разблокировки недоступна.

Проверка должна учитывать все экземпляры процесса, включая запущенные от других пользователей.

## 5. Архитектура реализации

Я бы использовал следующий стек:

| Компонент                  | Технология                 |
| -------------------------- | -------------------------- |
| Windows Service            | C# / .NET                  |
| Сетевой Kill Switch        | Windows Filtering Platform |
| Мониторинг VPN             | Windows Network APIs       |
| Мониторинг процессов       | ETW + Windows Process APIs |
| Tray UI                    | C# / WPF                   |
| Настройки                  | JSON                       |
| Взаимодействие компонентов | Named Pipes                |

Критически важный момент: сетевой Kill Switch должен работать независимо от GUI и не отключаться при падении службы или закрытии Tray-приложения. Политика блокировки должна сохраняться до безопасного восстановления управления.
